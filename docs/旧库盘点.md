# 旧库盘点

存储层设计时查旧系统数据用的手册。旧代码在 `reference/legacy/`（只读），连接方式见 `数据库连接配置.md`。盘点时间 2026-11-09，行数为当日快照。

## 总览

| 存储 | 内容 | 结论 |
|---|---|---|
| SQL Server `ccm` | 29 张表，主存储 | 迁移公共数据；其余被新设计取代或作废 |
| Redis | 63 键：`eva` list（任务队列，59）、`wecom` stream（入站事件，4） | MVP 单进程不需要；多 worker 时用作租约 |
| Qdrant | `kb_public_v1` 97563 点（dim 1024）+ 86 个 `kb_private_<hash>` 每 owner 集合（近半空） | 向量不迁移，做检索时按需重建 |
| Neo4j | 0 节点，从未使用 | 不引入图库，关系穿透从关系表算起 |

**迁移范围：仅公共数据。** 公司主数据、别名、上市注册表、热词（新表形状已定，直接迁）；公共事实、来源、线索等飞轮种子是否迁移，飞轮设计时定。联系人、会话、文件、账本一律不迁。

## 迁移：公共数据（新表形状已定）

### companies（4428）
公司主数据，`company_id` 即统一社会信用代码。
`company_id(=USCC), sec_code, exchange, short_name, full_name, listed_at, delisted_at, updated_at`

### company_aliases（15868）
公共别名。`alias_kind` 见过 FORMER（曾用名）、XD 前缀（除息日行情别名）等。
`alias_id, company_id(=USCC), alias, alias_kind`

### listed_company_registry（5945）
上市注册表，离线任务同步，first_seen/last_seen 是同步簿记。
`registry_id, exchange, sec_code, short_name, full_name, listed_at, delisted_at, status, source, first_seen_at, last_seen_at, updated_at`
迁移时并入公司主数据（sec_code、上市状态、交易所），同步簿记不迁。

### asr_hotwords（9515）
ASR 热词，离线维护，全局公共。
`hotword_id, term, source_kind, company_id(=USCC 可空), weight, industry, created_at`

## 候选迁移：飞轮种子（飞轮设计时定去留）

- **fact_claims（126637）**：公司事实主张。`claim_key` 语义主键，`anchor_json`（qcc_tool / qcc_subject / qcc_key）是出处锚点，带 `trust_level`、`valid_from/valid_to`、`observed_at/period_end`。`vote_unit / trust_rank / counts_in_vote` 是投票闭包，**作废不迁**。`fact_claims_history`（5688）与主表同构，历史版本表。
- **sources（677）+ source_domains（17）+ source_groups（5）**：来源信任登记（trust_level、default_evidence_kind、target_table、acquisition；domain→source 映射；来源分组）。飞轮设计的参考。
- **lead_items（4919）**：公司线索（标题、摘要、URL、发布日期、trust_level）。
- **documents（51976）**：抓取文档原件（owner_id 为空即公共抓取，非空为租户文件）。原件可继续用；`chunks`（98894）与 `doc_sections`（84334）属旧解析流水线，不迁，新系统读时解析、按需重建。

## 不迁移：租户私有与旧流水线

- **tenants（380）**：就是外部联系人（企微 `wma…`、网页 `ui_user_*`）。新系统租户=联系人，天然一一对应但不迁数据。`minio_bucket`、`qdrant_ready` 是"每租户一个桶/一个集合"的旧基础设施映射，新设计无此物。
- **sessions（456）**：state/end_reason 状态列由 transcript 推导取代。
- **conversation_turns（6036）**：每轮一行、text 截断 8000、无工具调用事件——不是事件日志，被 transcript 取代。
- **tasks（7780）**：scenario 枚举 + state 列 + `task_envelope/result_envelope` 信封，反面教材实物。
- **plan_traces（17773）**：编排步骤轨迹，被 transcript + 账本取代。
- **reports（354）**：报告产物登记（md_key/pdf_key、页数、脚注数）。新系统产物锚点记在 transcript，不另建表。
- **file_registry（256）**：形状可参考（sha256、minio_key_raw/md）；`parse_state` 状态机作废；`minio_key_md` 本质是解析缓存产物，新表用（租户，哈希）缓存键。
- **batch_file_members（374）**：上传批次分组。新系统不做批次，各文件独立。
- **cost_events（11154）**：只追加账本，`pricing_version`、`cache_hit/miss_tokens`、`asr_seconds` 三样吸收进新账本；缺预扣/结算/释放与幂等键。
- **tenant_usage_daily（198）**：派生聚合落表，从事件推导取代。
- **collection_tasks（5531）/ collection_runs（22）**：采集任务队列与批次。队列数据可由来源与公司重导出，不迁；attempts / max_attempts / last_error_* 的重试形状留作飞轮设计参考。
- **bak_20261104_private_chunks（600）、bak_20261104_private_documents（145）、bak_20261106_private_reports（2980）**：手工备份表，作废。
- **dup_clusters（0）**：simhash 去重，从未启用。

## 教训

1. Qdrant 每 owner 一个集合 → 86 个集合近半空置。以后检索用**一个集合 + payload 过滤**。
2. 生产库里出现手工 bak_* 表和从未启用的空表——新系统的表变更走迁移脚本，不手工改库。
3. Neo4j 申请了资源从未使用——图库不预建。
4. 旧库多处同义重复（tenant_usage_daily 对 cost_events 聚合、fact_claims_history 对 fact_claims 复制）——派生数据不落表。
